## 1. Robots.txt

**Status**: Hetzner serveert sinds vandaag eigen robots.txt via origin, maar Cloudflare overschrijft 'm edge-side met hun managed versie.

**CF managed versie**:
```
User-agent: *
Content-Signal: search=yes,ai-train=no
Allow: /
```

**Onze origin versie** (niet zichtbaar via CF):
```
User-agent: *
Content-Signal: search=yes,ai-input=yes,ai-train=no
Allow: /
```

**Wat het verschil betekent**:
- `search=yes`: zoekmachines mogen indexeren (beide)
- `ai-train=no`: AI training verboden (beide)
- `ai-input=yes`: AI search/RAG/citation toegestaan (alleen onze versie)

Default zonder `ai-input`: "neither granted nor restricted". Meeste AI search engines (ChatGPT, Perplexity, Claude) interpreteren dit als default-allow voor grounding/citation.

**Risico**: LAAG. De impact van het verschil is marginal. AI search engines blijven crawlen.

## 4. Schema markup (KRITIEK)

### Homepage schema
Volledig: WebPage + WebSite + Organization + BreadcrumbList + SearchAction + ImageObject. Organization heeft sameAs naar Facebook/Instagram/Pinterest. ✅

### Product pagina schema (FOUT)
Gegenereerd: WebPage + WebSite + Organization + BreadcrumbList + ImageObject

**MIST**:
- `Product` schema
- `Offer` schema (prijs, valuta, voorraad)
- `AggregateRating` schema (sterren)
- `Review` schema

**Gevolg**:
- Geen "Product rich result" in Google (prijs/voorraad/sterren ontbreken in zoekresultaat)
- Geen "Buyable Product" eligibility
- Geen Google Shopping organic listings
- AI search heeft geen prijs/availability te citeren

**Oorzaak**: Yoast heeft `enable_schema: True` maar **NIET** de Yoast WooCommerce SEO addon geïnstalleerd. Zonder die addon:
- Yoast suppresses WooCommerce's eigen ingebouwde Product schema (om dubbeling te voorkomen)
- Yoast genereert zelf geen Product schema als vervanging
- Resultaat: GEEN Product schema in HTML

**Drie oplossingen**:

1. **Yoast WooCommerce SEO addon kopen** (~€99/jaar) - simpelste, beste integratie
2. **WooCommerce native schema forceren via mu-plugin** - gratis maar custom code
3. **Schema plugin gebruiken** (bv. Schema Pro, RankMath Schema) - alternatief

**Aanbevolen**: optie 2 (custom mu-plugin). Hieronder een werkend snippet:

```php
<?php
/**
 * mu-plugin: bcw-wc-product-schema.php
 * Force WooCommerce native Product schema te outputten,
 * ook wanneer Yoast actief is.
 */
add_filter( 'wpseo_schema_graph_pieces', function( $pieces, $context ) {
    if ( is_product() && function_exists( 'wc_get_product' ) ) {
        $product = wc_get_product( get_the_ID() );
        if ( $product ) {
            $piece_data = [
                '@type' => 'Product',
                '@id' => get_permalink( $product->get_id() ) . '#product',
                'name' => $product->get_name(),
                'description' => wp_strip_all_tags( $product->get_short_description() ?: $product->get_description() ),
                'image' => wp_get_attachment_url( $product->get_image_id() ),
                'sku' => $product->get_sku() ?: (string) $product->get_id(),
                'url' => get_permalink( $product->get_id() ),
                'offers' => [
                    '@type' => 'Offer',
                    'price' => $product->get_price(),
                    'priceCurrency' => get_woocommerce_currency(),
                    'availability' => $product->is_in_stock()
                        ? 'https://schema.org/InStock'
                        : 'https://schema.org/OutOfStock',
                    'url' => get_permalink( $product->get_id() ),
                ],
            ];
            // Add rating only if real reviews exist
            $rating = $product->get_average_rating();
            $count  = $product->get_review_count();
            if ( $count > 0 && (float) $rating > 0 ) {
                $piece_data['aggregateRating'] = [
                    '@type' => 'AggregateRating',
                    'ratingValue' => (string) $rating,
                    'reviewCount' => (string) $count,
                ];
            }
            $pieces[] = new class( $piece_data ) {
                private $data;
                public function __construct( $data ) { $this->data = $data; }
                public function is_needed() { return true; }
                public function generate() { return $this->data; }
            };
        }
    }
    return $pieces;
}, 10, 2 );
```

Plaats deze als `/wp-content/mu-plugins/bcw-wc-product-schema.php` op de server (vergeet niet ook in de repo onder `oz-theme/inc/` of als losse mu-plugin file).

## 5. Reviews collection (KRITIEK voor social proof)

**Status DB**:
- 14 reviews totaal in `OTBgD_comments WHERE comment_type='review'`
- 0 producten met `_wc_average_rating > 0`
- Google reviews apart in `OTBgD_trustindex_google_reviews` (via Trustindex plugin)

**Twee plugins beheren reviews**:
- `customer-reviews-collector-for-woocommerce`: verzamelt reviews door follow-up emails
- `wp-reviews-plugin-for-google`: toont Google reviews + bedrijfsreviews

**Probleem**:
- Op 266 publieke producten zijn er 14 reviews = 5% review rate
- Met Product schema (zie #4) zou je per product de sterren en review count tonen
- Zonder voldoende reviews per product werkt AggregateRating ook niet
- Google's "Buyable Product" trigger heeft 1+ review nodig

**Aanbevelingen**:
1. **CRR follow-up emails activeren/verifiëren**: stuurt automatisch review-verzoek N dagen na levering
2. **Trustindex toont bedrijfsreviews op homepage**: check of dit ook product-specifieke reviews kan importeren
3. **Manual reviews migratie**: als er reviews op Trustpilot/Kiyoh/Google staan, kunnen die soms naar productpagina's getrokken
4. **Reviews op product page prominenter tonen**: laat zien aan klant + Googlebot
